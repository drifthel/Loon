Loon Plugins

一个持续维护与优化的 Loon 插件集合。

致力于改善 iOS 网络使用体验，提供广告过滤、网页增强、请求优化及个性化规则。

✨ Features

* 广告过滤：减少 App 开屏广告、信息流广告及推广内容
* 网页增强：优化网页浏览体验，清理不必要的推广元素
* 请求优化：过滤不必要的网络请求
* 自定义配置：支持按需启用和关闭不同功能
* 持续维护：根据应用更新和实际使用反馈持续优化
